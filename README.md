# 🚀 QubitScope – Quantum Visual Simulator

## 🔬 Overview

QubitScope is an interactive quantum simulation tool that visualizes the evolution of a single qubit using a Bloch sphere. The simulator demonstrates how quantum gates transform quantum states in real time.

---

## 🎯 Features

* 🌐 Interactive 3D Bloch Sphere visualization
* ⚡ Quantum gate operations (X, Hadamard, Z)
* 📊 Real-time measurement probabilities
* 🧠 State representation in Dirac notation
* 📜 Gate history tracking

---

## 🧠 Concepts Demonstrated

* Qubit and superposition
* Bloch sphere representation
* Quantum gates and state rotation
* Measurement probabilities

---

## 🛠 Tech Stack

* Python
* Streamlit
* Qiskit
* Plotly
* NumPy

---

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
